# 🏝️ Bouvet Island

**Et helt nytt SNES-spill fra 2026!**

Bouvet Island er et norsk homebrew-spill utviklet for **Super Nintendo Entertainment System (SNES)**.

Bli med på et iskaldt actioneventyr på Bouvetøya! Utforsk snødekte landskap, overvinn hindringer og kjemp mot hissige pingviner med krone.

Spillet er laget med kjærlighet til klassiske 16-bit-spill, retrospill og teknologi.

## 🎮 Om spillet

- **Plattform:** Super Nintendo (SNES)
- **Sjanger:** Plattform / Action
- **Utgivelsesår:** 2026
- **Språk:** Norsk
- **Pris:** Gratis

Bouvet Island er et homebrew-prosjekt, utviklet for å kunne spilles på original SNES-maskinvare eller via emulator.

## ⬇️ Last ned spillet

Den nyeste versjonen av Bouvet Island finner du under:

**[Last ned Bouvet Island](../../releases/latest)**

Last ned ROM-filen (`.sfc`) fra den nyeste utgivelsen.

### Slik spiller du

1. Last ned ROM-filen fra Releases.
2. Åpne filen i en SNES-emulator, for eksempel Snes9x.
3. Start spillet og utforsk Bouvet Island!

Du kan også spille på original SNES-maskinvare med kompatibel flash cartridge.

## 🔬 Laget på Labben i Bouvet

Bouvet Island er et prosjekt fra **Labben på Bouvet**.

Labben er vår lekeplass for teknologi, eksperimentering og skaperglede. Her utforsker vi blant annet:

- IT og programvareutvikling
- IoT og smarte dingser
- Elektronikk og mikrokontrollere
- Makerspace, prototyping og kreative prosjekter
- Retrospill og gammel maskinvare

Vi liker å utforske ny teknologi – og av og til lage noe for teknologi som er over 30 år gammel.
